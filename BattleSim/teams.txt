# ==============================================================================
# Battle Simulator - équipes
#
# Format d'export de Pokémon Showdown : copiez-collez vos équipes depuis le
# teambuilder (bouton "Import/Export"). Une équipe commence par une ligne
#   === [format] Nom de l'équipe ===
# et contient jusqu'à 6 Pokémon séparés par une ligne vide.
#
# Dans le menu du simulateur, choisissez l'équipe du joueur et celle de l'IA
# avec Gauche/Droite. Ce fichier est relu à chaque combat (option "Recharger
# les équipes" dans le menu) : inutile de relancer le jeu après une modification.
#
# Valeurs par défaut quand une ligne est absente (comme Showdown) :
#   Level 100, IV 31, EV 0, bonheur 255, nature neutre, 1er talent de l'espèce.
# Lignes ignorées : Tera Type, Gigantamax, Dynamax Level, Hidden Power.
# Lignes en plus : "Form: 2" (numéro de forme Essentials), "Ball: Ultra Ball".
# Les lignes commençant par # sont des commentaires.
# ==============================================================================
